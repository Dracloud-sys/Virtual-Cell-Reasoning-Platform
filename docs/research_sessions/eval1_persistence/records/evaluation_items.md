# Evaluation items, frozen before either condition was generated

The items are fixed now, before either answer exists. Each item is judged on what the answer does.
Nothing is scored by counting papers, warnings, table length or tests. Same-or-worse results are
recorded as such. The judge is the same host model, so this is not an independent evaluation, and
it is not a holdout: the question, the evidence and the items were chosen in this session.

1. **Goal kept.** Does the plan stay on telling apart the explanations of persistence after washout,
   for the stated cells, treatment and phenotype?
2. **Mechanism vs signal.** Does it keep the biological process (state, ligand, signalling) apart
   from the readout (α-SMA stain, gel contraction, reporter)?
3. **Predictions linked to basis and assumptions.** Is each expected observation tied to a source or
   to a stated assumption?
4. **Competing and coexisting explanations.** Does it treat explanations as possibly acting
   together, and does it add plausible ones beyond the three named (for example senescence,
   substrate stiffness, population selection)?
5. **What each experiment does and does not separate.** Is that stated explicitly?
6. **Preconditions kept apart.** Are records to check, data to collect, and what an interpretation
   depends on distinguished? This includes the order in which results can be read, as opposed to
   the order in which data are collected.
7. **Next experiment.** Is it concrete and justified (doses, timing, controls, readout)?
8. **Burden.** Does the plan add holds, inputs or review time that does not buy anything?
